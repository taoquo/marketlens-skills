# Base Rates

A probability with no reference class is a guess with a decimal point. Before
assigning any probability, weight, or scenario likelihood, state the reference
class and its historical rate, then explain why this case differs.

## When A Base Rate Is Mandatory

- Any scenario tree with numeric probabilities.
- Any claim that an event is `likely`, `unlikely`, or `priced in`.
- Any turnaround, margin-recovery, share-gain, or first-product-launch thesis.
- Any multi-year forecast that assumes a rate of change persists.
- Any merger, approval, license, or court outcome.

If no reference class can be found, say so, use directional language instead of a
number, and cap confidence at Medium.

## Reference Class Construction

1. Name the class: what population of past cases does this case belong to.
2. Set the boundaries: geography, period, size, stage, and market structure.
3. Find the historical rate from a source that predates the current case.
4. State the sample size. A rate from fewer than roughly 20 cases is an anecdote.
5. Adjust for what is genuinely different here, and say how much each adjustment moves the number.
6. Keep the unadjusted base rate visible next to the adjusted estimate.

The adjustment step is where most error enters. Every argument for why this case
beats the base rate must name evidence, not conviction.

## Common Reference Classes

| Question | Reference class | Where to look |
|---|---|---|
| Will this drug be approved | Phase-specific success and approval rates by therapeutic area | FDA and EMA statistics, BIO and industry success-rate studies, prior decisions in the same class |
| Will this merger close | Completion rate by deal type, size, and antitrust or national-security exposure | Prior deals in the same regulator and sector, current spread versus deal terms |
| Will guidance be met | The company own history of guidance versus actuals over 8 to 12 quarters | Prior releases and transcripts |
| How long does this downcycle last | Duration of prior troughs in the same industry | Prior cycle data on inventory, utilization, price, and orders |
| Will margin recover to prior peak | Frequency of full margin recovery after a comparable compression | Company and peer history, and whether the cause was cyclical or structural |
| Will the turnaround work | Base rate of successful turnarounds in the same industry and leverage band | Peer history, prior attempts by the same management |
| Will capacity additions cause oversupply | Prior capex cycles in the same industry | Announced versus commissioned capacity, prior cycle price outcomes |
| What happens after this event type | Post-event drift and reversal behaviour for that event class | The company own prior reactions to the same event, plus peer reactions |
| Will a new entrant take share | Share-gain rate for entrants against incumbents with similar switching costs | Prior entrants in the same market |
| Will this litigation be material | Settlement versus judgment rates and typical size in the same venue and claim type | Prior comparable cases |
| Will the policy be implemented as drafted | Rate of draft-to-final change in that jurisdiction and policy area | Prior consultation cycles in the same regulator |

## Company Self-History First

The cheapest and most relevant base rate is usually the company own record. Before
reaching for an industry statistic, check:

- Guidance versus actuals, by metric, over the last 8 to 12 quarters.
- Prior announced targets, capacity plans, or launch dates versus what was delivered, and the length of each slip.
- Prior reactions to the same event type, in absolute and relative terms.
- Prior equity or debt issuance after similar cash-burn periods.

A management team that has missed a target four times running does not get a base
rate; it has an established rate.

## Recording The Base Rate

When probabilities appear in an output, add this table:

| Claim | Reference class | Base rate | Sample | Adjustment and evidence | Adjusted estimate |
|---|---|---|---|---|---|

Carry the same table into the research log so a later review can separate a bad
base rate from a bad adjustment.

## Failure Modes

- Reference-class shopping: narrowing the class until the rate matches the desired answer. Fix the class before looking at the rate.
- Inside-view override: rich case detail replacing the historical rate entirely.
- Survivorship: sampling only companies or deals that still exist or still trade.
- Regime break: using a pre-regime-change rate without saying what changed.
- False precision: reporting 63 percent from a sample of nine.
- Double counting: the same driver supporting both a high base rate and a large upward adjustment.
